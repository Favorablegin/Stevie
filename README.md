# Stevie · Trainings-App

Mobile Web-App zum 12-Wochen-Trainingsplan für Stevie (CAMELIDynamics). Protokoll, automatische Weiter-Regel, Signal-Tracking, Muster, Abzeichen, Briefe von Stevie und der komplette Plan zum Nachschlagen.

- Reines HTML/CSS/JS, kein Build. Läuft über GitHub Pages (Branch `gh-pages`).
- Daten: lokal im Browser + Sync über textdb.online unter dem geheimen Stall-Code (`?s=…` in der URL).
- Inhalte: `content.js`, Logik: `app.js`, Styles: `style.css`, Offline: `sw.js`.
